## 遇到的问题和解决

### 问题1: SSH密码认证失败
**现象**: Git Bash的ssh命令无法交互式输入密码

**尝试方案**:
1. sshpass工具 - 未安装
2. expect脚本 - 未安装
3. PowerShell SSH模块 - 未安装

**最终方案**: Python paramiko库实现SSH连接

### 问题2: 远程无git仓库
**现象**: 无法通过git pull同步代码

**原因**: 远程工作目录不是git仓库

**解决**: 直接通过SFTP上传文件

### 问题3: Python环境限制
**现象**: pip install被PEP 668 externally-managed-environment阻止

**影响**: 无法安装pytest进行单元测试

**应对**: 改为文件部署完整性验证，依赖实际训练验证功能

### 问题4: 导入路径混淆
**现象**: 先后尝试导入autotuner.locomotion_console.research_ledger和autotuner.research.research_ledger

**原因**: research_ledger.py同时存在于两个位置，但checkpoint_curator.py导入的是autotuner.research版本

**解决**: 上传autotuner/research/research_ledger.py (正确版本)
