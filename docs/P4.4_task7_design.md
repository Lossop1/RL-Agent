**每个 kind 的编码**：

| kind | 维数 | 编码 | 依据 |
| --- | --- | --- | --- |
| `continuous`, `log=False` | 1 | `(x - low) / (high - low)` | `HyperparameterSpec.low/high`（`hyperparameter_space.py:273-274`） |
| `continuous`, `log=True` | 1 | `(ln x - ln low) / (ln high - ln low)` | `log: bool`（`:276`）；同 `draw_value` 对 log 的处理（`hyperparameter_sampler.py:490-493`） |
| `discrete` | 1 | `index / (count - 1)`，`index` 由 `discrete_value`/`_discrete_offset` 求得 | `discrete_count()`（`:407`）、`discrete_value()`（`:413`） |
| `categorical` | `k` | one-hot | `choices`（`:277`） |

**退化维**（必须显式处理，否则是除零）：

- `discrete_count() == 1`：`count - 1 == 0`。该维恒为 `0.0`。
- 类别数 `k == 1`：该维恒为 `1.0`。
- `low == high` 的连续维：**不可达，编码器因此没有这一分支**。设计稿原先把"该维恒为 `0.0`"写成
  第三条，但 `HyperparameterSpec` 在构造时就拒绝等界的连续域（"low must be strictly below
  high"），所以 `(x - low) / (high - low)` 永远遇不到 `high - low == 0`。实测见
  `test_a_continuous_domain_with_no_room_is_refused_by_the_space_itself`；模块在
  `_encode_continuous` 的 docstring 里就地记了这条理由。一个恒 0 的分支会是无人可执行的代码，
  也会让读者以为账本里可能存在等界连续域。

**条件参数的"生效位"**：`condition is not None` 的参数可以失效（`hyperparameter_space.py:177-193`、
`is_active` `:697-701`，**读码**）。失效时它的值维全部记 `0.0`，并在 `activity_dim` 上记 `0.0`；
生效时 `activity_dim` 记 `1.0`。

> 为什么要有这一位：没有它，"参数未生效"和"参数生效且取到了下界"编成同一个向量，
> 代理模型会认为这两个点一模一样。这不是精度问题，是把两种不同的试验当成同一个点。

### 3.2 代理模型：纯 Python 的高斯过程

```python
class GaussianProcess:
    """零均值先验 + RBF 核的 GP 后验，纯 Python，无 BLAS。"""

    def __init__(self, *, length_scale: float, noise: float, train_x, train_y): ...

    def predict(self, point: Sequence[float]) -> tuple[float, float]:
        """后验均值与方差。方差已截断到非负。"""
```

数学（写进 docstring，并**逐条对照**实现）：

- 核：`k(p, q) = exp(-0.5 * Σ ((p_i - q_i) / ℓ)²)`，单位立方体上的固定长度尺度 `ℓ`。
- 观测模型：`y = f(x) + ε`，`ε ~ N(0, noise)`，对角抖动即 `noise`。
- 后验：`μ(x) = k(x)ᵀ K⁻¹ y`，`σ²(x) = (1 + noise) - k(x)ᵀ K⁻¹ k(x)`，
  其中 `K = [k(xᵢ,xⱼ)] + noise·I`。
- 求解用 **Cholesky 分解**（`K = LLᵀ`），不用求逆。`d = K_ii - Σ L_ik²  <= 0` 时**抛错**，
  不把非正定矩阵当正常情况糊过去。

**实测**（§11.1）：`n=5, d=4, ℓ=0.5, noise=0.01` 时 Cholesky 对角为
`[1.004988, 0.966158, 0.963393, 0.726676, 0.643719]`，全部为正；同一个查询点算两次结果**逐位相同**。

### 3.3 采集函数：EI

```python
def expected_improvement(mu: float, sigma: float, best: float, *, xi: float) -> float:
    """最大化方向的期望增量。sigma<=0 返回 0.0。"""
```

- `z = (μ - best - ξ) / σ`，`EI = (μ - best - ξ)·Φ(z) + σ·φ(z)`。
- `Φ` 用 `math.erf`：`Φ(z) = 0.5 * (1 + erf(z / sqrt(2)))`；`φ(z) = exp(-z²/2) / sqrt(2π)`。两者都在标准库。
- **最小化方向**在编码成训练集时取负（`y' = -y`），策略永远"最大化 `y'`"。
  这样只有一处处理方向，而不是每个公式里各判一次。

**实测**（§11.1）：`μ=-0.109735, σ=√0.47105397=0.686334, best=-0.1725, ξ=0.01` → `EI=0.300999`。
同一组输入重复计算逐位相同。

`mode` 的三态是刻意的：

- `initial_design`：观测不够 `min_train`，照随机设计抽（冷启动）。

- `fallback`：够数了但**建不了后验**（例如所有 y 相同 ⇒ 标准差为 0），退回池内抽样。
  这一态必须与 `surrogate` 分开记：把它混进 `surrogate` 会让人以为那一步有模型在起作用。

### 3.6 `BayesianSampler`

```python
class BayesianSampler(Sampler):
    """一步一步地抽：每一步先读观测，再建后验，再按 EI 挑一个。"""

    def __init__(
        self,
        space: SearchSpaceSchema,
        plan: SearchPlan,
        *,
        observations: TrialObservationSource,
        sink: SurrogateSink | None = None,
    ) -> None: ...

    def _candidates(self) -> Iterator[dict[str, Any]]: ...
```

`_candidates` 是**生成器**，这是整个设计能"零改动接进任务 4"的原因（§5.5）：

```
for step in range(1, budget + 1):
    seen   = 本 run 已提议过的 ∪ index < step 的已记录 assignment_key（含 failed/pruned）
    prefix = [r for r in observations.observations(plan_fp, space_fp) if r.index < step]
    train  = [r for r in prefix if r.status in learn_from and r.objective is not None]
    if len(train) < min_train:  → 池里挑一个没见过的（mode=initial_design）
    else:                       → 建后验、给整个池打 EI、取 argmax（mode=surrogate）
    candidate = 选中的那个
    space.validate_assignment(candidate)
    stats.proposals += 1
    yield candidate
stats.exhausted = True
```

三处**必须**写清楚的地方：

1. **`seen` 用全部已记录试验，`train` 只用 `learn_from` 里的终局。** 两个集合不同（§5.3）。
   落地时这里还有第三件事，原先的伪代码漏了、审阅时被点出来：`seen` 只取 **`index < step`**
   的已记录试验（外加本 run 自己提议过的）。所以第 1 步可以恰好提出第 1 条试验记下的那个点——
   那时它还不存在。钉住它的是
   `test_a_search_whose_every_trial_was_pruned_never_consults_a_posterior`：同一个 plan、
   同一颗 seed，有证据的第一条提议与完全无证据时**相同**；而第 2 步的池子少 2 个而不是少 1
   （既排除自己的提议、也排除那条 pruned 试验），这条差值才是"`seen` 含 pruned、`train` 不含"
   与"两个集合都是 `train`"的区别。变异验证：把 `records` 换成 `records[:0]`（`seen` 空），
   该用例失败（§12.2）。
2. **同分时按池内下标取先者。** EI 在未探索区域是一片平地，"谁赢"经常由同分决定。
   规则已写进 `choose_next` 的 docstring（`scores.index(best)`，不是重排后取首）；
   下标本身来自一条确定的随机流（§5.7），所以仍然可复现。
   钉住它的是 `test_a_pool_where_every_candidate_ties_takes_the_first_one_in_pool_order`：
   `noise=0.0` 且池子由训练点组成时，每个候选的 EI 都恰好是 `0.0`（后验在训练点上精确复现
   target，"还是原来那个值"的 EI 就是 0），于是整池同分、`chosen_key == pool[0]`、
   `runner_up_ei == 0.0`（同分有亚军，不是 `None`）。断言写的是 `pool[0]` 而不是某个具体
   assignment——池子顺序不是排过序的、也不能从空间推出来，所以"按 key 排序后再打分"或者
   "取最后一个最大值"这类改写会返回**另一个**候选：这正是这条断言能失败的原因。
   变异验证：把 `scores.index(best)` 换成取**最后一个**最大值的下标，该用例失败（§12.2）。
3. **池里挑不出新点就抛错**，错误信息按原因分类计数——照 `_describe_dead_end`
   （`hyperparameter_sampler.py:429-469`）的手法：把"约束挡了多少次"和"重复了多少次"分开数。
   （这个行号以及本文其余指向 `hyperparameter_sampler.py`/`hyperparameter_search.py` 的行号
   已按**工作区**重新量过一次：本节初稿是在任务 7 改动那两个文件**之前**读的码，
   旧行号是 `:375-415`。同一批订正的完整清单见 §11.2 的开头。）

### 5.2 "bayesian" 不进 `REPLAYABLE_SAMPLER_KINDS`——而 A23 的断言与它自己的 docstring 矛盾

### 5.3 训练集只取 `succeeded`——这不与任务 6 的"pruned 也计分"冲突

任务 6 明确写过（`search_analysis.py:1084-1089`，**读码**）：

> `{len(pruned)} pruned trial(s) carry a score and are ordered alongside the trials that ran to
> an end: being stopped early is not the same as having no result`

**排序**上：一个被剪掉的试验有一个真实读到的分数，它就该参与排序——任务 6 是对的。
**回归**上：`objective` 是在**截断的时长**上测出来的。把截断时长上的 y 和跑满时长的 y
放进同一个训练集，等于教代理模型一个**并不存在**的映射：同样一个 x，"跑满"和"跑到一半"
会给出两个不同的 y，而模型只看到一对 `(x, y)`。

所以本模块默认 `learn_from = ("succeeded",)`，并且**是记录中的字段**：
要把 pruned 也算进来的人可以改策略，但那个决定会印在策略指纹里，不会悄悄发生。

**可测的后果**（§9 组 D）：一个所有试验都被剪短的 run，`train_count` 恒为 0，
采样器**永远走 `initial_design`**——它不会"就着截断的 y 建了一个后验"。

### 5.4 不拟合核超参

拟合（比如对边际似然做优化）会引入：一个优化循环、一个收敛判据、一堆初始值，
以及在 n 很小的时候**极不稳定**的解。而本模块的 n 是"搜了多少个试验"，通常是个位数到几十。
代价是长度尺度需要调用方给，且给得不合适时模型很差（§11.1 的探针就是这种情形）。
这个取舍的**代价写在 §7 风险 R-1**，不假装它不存在。

### 5.5 为什么零改动就能接进任务 4 的循环

`SearchTracker.run()` 的循环（`hyperparameter_search.py:1187-1188`，**读码**）：

```python
sampler = self._sampler if self._sampler is not None else build_sampler(self.space, self.plan)
for index, assignment in enumerate(sampler.proposals(), start=1):
```

`proposals()` 是生成器，而循环体里 `self.runner.run(request)` **是同步阻塞**的。
所以第 N+1 次推进生成器时，第 N 个试验的终局记录**已经落盘**。
自适应采样器要的正是这个时间顺序，而它已经成立。

**这是一条隐式契约，必须钉住**：一条用例（§9 组 C）用一个记账的假 runner，
断言"抽第 n 个点时读到的观测恰好是前 n-1 个"，把"循环是惰性拉取 + 逐条同步执行"这件事
变成可执行的断言。它一旦被改成批量并发，这条用例会红，而不是让自适应悄悄退化成随机。

`SearchTracker.__init__` 已经接受 `sampler: Sampler | None = None`（`:904-974`，形参在 `:916`，**读码**），
所以调用方这样接线：

```python
tracker = SearchTracker(..., sampler=BayesianSampler(space, plan, observations=ledger))
```

**并发的限制**：`max_in_flight > 1` 时，同一批里的点是在看到彼此结果**之前**抽的，
"自适应"就名不副实。所以 `BayesianSampler` 拒绝 `SearchTracker` 的批量语义——
具体做法见 §6 第 9 条（策略里记 `max_in_flight`，或用例断言批大小为 1）。

### 5.6 `direction` 没有默认值，且方向词表不能 import

`RankingRule.direction` 是**无默认值**的必填参数，理由写得很清楚
（`search_analysis.py:330-341`，**读码**）："一个抛硬币的默认值是个看不见的决定"。
本模块的 `direction` 同理，无默认值。

但**不能** `from .search_analysis import RankDirection`：

```
search_analysis → search_pruning → hyperparameter_search → hyperparameter_sampler
                 ↑                                                        │
                 └──────────────── 循环 ───────────────────────────────────┘
```

（**读码**：`search_analysis.py` 的 import 段、`search_pruning.py:45-53` 的 import 段、
`hyperparameter_search.py:82-89` 的 import 段。）从 `hyperparameter_sampler` 反向 import
`search_analysis` 会在 import 期就炸。

所以本模块自带一个字面相同的 `Direction`，并由**测试**（测试不在循环里）钉住两边一致：

```
test_the_direction_vocabulary_matches_the_ranking_layer
    get_args(bayesian_sampler.Direction) == get_args(search_analysis.RankDirection)
```

### 5.7 每一步一条独立的随机流

池子的抽样用 `random.Random(f"{plan.seed}:{plan.fingerprint()[:16]}:{step}")`，
**不是**一条从第 1 步流到第 N 步的流。

理由是可恢复性。用一条连续的流时，"第 5 步的池子长什么样"取决于前 4 步各消耗了几个随机数，
而消耗量取决于那时的拒绝次数；于是**从头重建状态**必须把前 4 步整个重跑一遍，
而且必须重跑得**一模一样**。用每步一条独立的流，第 N 步的池子只由
`(seed, plan, step)` 决定，重建时不需要重放任何东西。

字符串种子：CPython 的 `random.seed(str)` 走 `sha512`（version=2），是文档化的稳定派生
（**读码**：标准库 `random.py` 的 `seed` 文档字符串；**未验证**：跨 Python 大版本的稳定性，
见 §11.4）。同一进程内、同一版本内逐位可复现（§11.1 实测验过）。

### 5.8 任务 6 coverage 表里那句依据即将失效

`search_analysis.py:814-818`（**读码**）现在这么写：

> ``kind`` is compared to ``"grid"`` and everything else -- including a kind this version has
> never heard of -- takes the non-grid rows. That is a real limit worth stating: a third
> ``SamplerKind`` would already be refused by ``SearchRunRecord``'s own validator when the
> ledger is read (it re-validates the plan, ``hyperparameter_search.py:320``), so this
> function's tolerance is about not adding a *second* place that has to know the vocabulary.

后半句在 `"bayesian"` 落地后**不成立**：那时 `"bayesian"` 是个合法 kind，
`SearchPlan.model_validate` 不会拒它，它会安静地走 non-grid 两行
（`drew_its_budget` / `stream_ended_early`）。

**行为不用改**（non-grid 那两行的措辞本来就是"一个不是网格的计划"，对自适应同样成立），
但**依据必须改**，否则下一个人会读到一个过期的前提。
本任务改的是那段 docstring，并补一条用例钉住"`kind="bayesian"` 会得到
`drew_its_budget` 而不是抛 `ValidationError`"（§9 组 G）。

### 5.9 计划加字段的兼容性代价（必须写明）

`SearchPlan` 加 `policy` 字段后，**每一个 plan 的指纹都会变**：

`SearchPlan.fingerprint()` 是 `content_hash(self.model_dump(mode="json"))`（`hyperparameter_sampler.py:191-204`，**读码**），
而 `model_dump(mode="json")` 包含带默认值的字段——所以哪怕 `policy=None` 也会出现在 dump 里。
新字段无法做到"旧指纹不动"。

后果，以及为什么可接受：

| 情形 | 结果 | 方向 |
| --- | --- | --- |
| 用旧版本写的 search root，用新版本 `replay_check` | `plan_match is False`，报"计划对不上" | **安全**：是假告警，不是漏报 |
| 同一 build 内反复跑 | 指纹稳定 | — |
| 仓库里有没有钉住旧指纹的资产 | **实测**：`tests/` 下没有 `*.jsonl` 台账固件，`grep` 也没有硬编码的 `search:` 指纹 | 无 |

代价落在一个假告警上，而不落在任何会被继承的事实上。这条写在这里，是为了让它**是**一个
被写下来的决定，而不是下一个人查半天的一个谜。

**落地后补记（实测）**：`grid` 与 `random` 计划的 `model_dump(mode="json")` 里确实出现了
`"policy": null`，所以它们的指纹也变了；`test_the_plan_fingerprint_changes_when_the_policy_changes_and_not_otherwise`
把两件事一起钉住——`for_grid()` 的 `policy is None` 且 dump 里含该键、以及同参数两次构造
指纹相同而策略不同则不同。表里"用旧版本写的 root 会得到假告警"这一行**仍未用旧台账实测**
（§11.4 第 6 条）。

## 7. 风险与未决问题

**R-1（高）长度尺度是个没人能定的数，而它决定一切。**
§11.1 的探针显示：固定 `ℓ=0.5` 时，未探索区域的 EI 高于真实最优点。
也就是说在观测很少时，这个采样器**主要是探索**，"利用"要到观测变密之后才出现。
本文不给默认值之外的任何保证，`length_scale` 的合适取值**本轮未验证**。

**R-2（中）EI 在同分时靠池内下标决定，而池子只有 `pool_size` 个。**
如果整个池子的 EI 都一样（冷启动附近很常见），选中的其实是"池子里第一个没见过的点"。
这是确定的、可复现的，但**不是**"最优的"。记录里的 `runner_up_ei` 与最优值的差
（通常为 0）就是这件事的证据。
这条规则现在写在 `choose_next` 的 docstring 里，并由
`test_a_pool_where_every_candidate_ties_takes_the_first_one_in_pool_order` 钉住（§6 第 13 条）。
**仍然是风险**：钉住的是"规则不会被悄悄改掉"，不是"这个规则选得对"。

**R-3（中）`learn_from=("succeeded",)` 在只有剪枝的搜索里会让模型永远冷启动。**
见 §5.3。这是有意的取舍，但使用者要知道：**先剪枝再自适应**这个组合下，
自适应可能一直没机会启动。

**R-4（低）每步都 `observations()` 会重读台账。**
`SearchLedger.refresh()` + `_folded_trials()`（`hyperparameter_search.py:566`、`:633`，**读码**）每步一次，
总读取量是 O(N²)。N 是几十的规模时无所谓；**未验证**：上千试验时的实际耗时。

**R-5（低）`random.seed(str)` 的跨版本稳定性未验证**（§5.7、§11.4）。
本模块的确定性主张只在**同一 Python 版本内**成立。

**R-6（已定，代价已知）`SearchPlan` 维度膨胀。**
`policy` 字段加进 plan 后，plan 的 `model_dump` 会带上一整块策略。
可选方案是把策略放进 `SearchRunRecord`（它不被哈希，加字段不影响任何指纹）。
本文选了放在 plan 里，理由是 plan 的 docstring 说自己就是"要重采一次所需的一切"，
而策略正属于这个范畴；但这个取舍**没有**被任何外部约束逼出来，是本文的选择。

**落地后的结论**：保持放在 plan 里。真实代价已在 §5.9 记明——所有种类的计划指纹都变了，
换来的是"计划本身就是重采的全部依据"这一条不变式：复核方只要拿到 plan 就能重算，
不必再去台账里找一条策略记录。反向的代价（策略与计划各存一份、可能对不上）也没有出现，
因为 `bayesian_plan()` 是唯一的构造路径，它把策略原文写进 plan（
`test_each_kind_of_plan_demands_exactly_the_fields_its_sequence_needs` 钉住
`plan.max_attempts == plan.policy["max_attempts"]`，即两者不会各说各话）。

2. **本轮有 30 处引用根本没查**，命令会把它们连行号一起打印出来（"没查过"这件事本身是可
   复核的）。其中 14 处是正文里自称"旧编号／第一次写下时"的历史数字（§3.6、§9、§12.3 各一
   些），它们不声称当前树的样子；另外 16 处是紧跟一个文件名的裸编号，落在 §1.3、§2、§3.1、
   §5.2、§5.5、§6、§7、§12.4。**"没被查"不等于"查过没问题"。**
3. 即便那 105 处全过，命令只证明**编号落在该符号（或该文件）的跨度内**，**不证明那句话描述的
   就是那几行**。语义要靠人读，这一条是它最大的边界。
4. 它对不带编号的断言一无所知（例如 §5.2 那句"`bayesian` 不进 `REPLAYABLE_SAMPLER_KINDS`"
   说的是语义，不是行号）。

一处环境依赖：`ROOT = ... .parents[1]` 假定脚本放在仓库根的**下一层**子目录里（本轮是
`.scratch_verify_v7/`）。存到别处就改这一行。`--basetemp` 之类与它无关；它只读

```python
"""Check every ``file:line`` reference in the design doc against the tree it names.

Two grammars are checked, both exact (no guessing at what a reference "probably" means):

  A. entry grammar   `Sym`（`:A-B`, ...）      see the doc's 11.2 preamble
                     `Sym`（旧 `:A-B`, ...）
                     `Sym`（注释 `:A-B`, ...）
                     `file`（`:A-B`, ...）
     Checked in the three sections that write references in it (9, 11.2, 12.3); the
     bullet header above the entry names the file.

  B. inline grammar  `path.py:A-B`            the file is inside the code span itself, so
                                              no context is needed and this one is checked
                                              doc-wide.
     For a .py file A..B has to fit inside ONE of: a node's span (def/class/assignment,
     grown upward over the blank and comment lines attached above it), or a run of
     *adjacent* top-level statements (a pair of constants, a whole import block).  For any
     other file A..B has to be within the file.

Unresolved references are printed as a list rather than ignored: a reference that neither
grammar matches is reported with its line number, so "not checked" is a reading of this
command and not a thing a reader has to take on trust.
"""
from __future__ import annotations

import ast
import pathlib
import re
import subprocess
import sys

ROOT = pathlib.Path(__file__).resolve().parents[1]
DOC = pathlib.Path(sys.argv[1]) if len(sys.argv) > 1 else ROOT / "docs" / "P4.4_task7_design.md"
HEAD = "HEAD"

ENTRY = re.compile(r"`([A-Za-z_][\w./]*)`\s*（(`:\d+(?:-\d+)?`.*?)）", re.S)
REF = re.compile(r"(旧 |注释 )?`?:(\d+)(?:-(\d+))?`")
BULLET = re.compile(r"^\s*- `([^`]+)`")
OLD_NAME = re.compile(r"那时它叫 `([\w.]+)`")
INLINE = re.compile(r"`([A-Za-z_][\w./-]*\.(?:py|toml|md|txt)):(\d+)(?:-(\d+))?`")
#: A line number written with a backtick but no colon is still a line number; without this
#: the guard could be escaped by dropping the colon.
BARE = re.compile(r"`(\d+(?:-\d+)?)`")
REGIONS = (("## 9. ", "## 10. "), ("### 11.2 ", "### 11.3 "), ("### 12.3 ", "### 12.4 "))

INDEX: dict[str, list[str]] = {}
_TREE: dict[str, ast.Module] = {}
SOURCE: dict[str, str] = {}


def region_of(text: str) -> tuple[str, list[int]]:
    """The checked sections, joined, plus the absolute offset of every character."""
    chunks: list[str] = []
    origin: list[int] = []
    for start, end in REGIONS:
        a, b = text.index(start), text.index(end)
        chunks.append(text[a:b])
        origin.extend(range(a, b))
    return "".join(chunks), origin


def build_index() -> None:
    proc = subprocess.run(["git", "ls-files"], cwd=ROOT, capture_output=True)
    for rel in proc.stdout.decode("utf-8").splitlines():
        INDEX.setdefault(pathlib.PurePosixPath(rel).name, []).append(rel)


def resolve(rel: str) -> str | None:
    """A bare basename resolves through the repository index, never by guessing."""
    if "/" in rel:
        return rel if (ROOT / rel).exists() else None
    if rel not in INDEX:
        # untracked-but-present files (this task's own deliverables) still resolve
        hits = [str(p.relative_to(ROOT).as_posix()) for p in ROOT.glob(f"**/{rel}")]
        return hits[0] if len(hits) == 1 else None
    hits = INDEX[rel]
    return hits[0] if len(hits) == 1 else None


def source_of(rel: str) -> str | None:
    if rel not in SOURCE:
        resolved = resolve(rel)
        if resolved is None:
            return None
        SOURCE[rel] = (ROOT / resolved).read_text(encoding="utf-8")
    return SOURCE[rel]


def head_source(rel: str) -> str | None:
    resolved = resolve(rel)
    if resolved is None:
        return None
    proc = subprocess.run(["git", "show", f"{HEAD}:{resolved}"], cwd=ROOT, capture_output=True)
    if proc.returncode != 0:
        return None
    return proc.stdout.decode("utf-8")


def nodes_with_spans(source: str) -> list[tuple[str, int, int]]:
    """(name, lineno, end_lineno) for every def/class/annotated-or-plain assignment."""
    out: list[tuple[str, int, int]] = []
    for node in ast.walk(ast.parse(source)):
        if isinstance(node, (ast.FunctionDef, ast.AsyncFunctionDef, ast.ClassDef)):
            out.append((node.name, node.lineno, node.end_lineno))
        elif isinstance(node, ast.AnnAssign) and isinstance(node.target, ast.Name):
            out.append((node.target.id, node.lineno, node.end_lineno))
        elif isinstance(node, ast.Assign):
            for target in node.targets:
                if isinstance(target, ast.Name):
                    out.append((target.id, node.lineno, node.end_lineno))
    return out


_SPANS: dict[str, list[tuple[int, int]] | None] = {}


def extended_spans(rel: str) -> list[tuple[int, int]] | None:
    if rel not in _SPANS:
        _SPANS[rel] = _compute_extended_spans(rel)
    return _SPANS[rel]


def _compute_extended_spans(rel: str) -> list[tuple[int, int]] | None:
    """The ranges a citation may point at, one node at a time.

    Each node's span grown upward over the blank and comment-only lines attached above it
    (the ``#:`` block that documents a constant, the banner above a test).  A citation has
    to fit inside ONE of these: allowing the lines to pool would let a range that straddles
    two unrelated tests pass.
    """
    source = source_of(rel)
    if source is None:
        return None
    lines = source.splitlines()
    if not rel.endswith(".py"):
        return [(1, len(lines))]
    if rel not in _TREE:
        _TREE[rel] = ast.parse(source)
    tree = _TREE[rel]
    base: list[tuple[int, int]] = [(a, b) for _, a, b in nodes_with_spans(source)]
    for node in tree.body:
        if isinstance(node, (ast.Import, ast.ImportFrom)):
            base.append((node.lineno, node.end_lineno))
    if (
        tree.body
        and isinstance(tree.body[0], ast.Expr)
        and isinstance(tree.body[0].value, ast.Constant)
        and isinstance(tree.body[0].value.value, str)
    ):
        base.append((tree.body[0].lineno, tree.body[0].end_lineno))
    inside = set()
    for start, end in base:
        inside.update(range(start, end + 1))
    out: list[tuple[int, int]] = []
    for start, end in base:
        top = start
        while top - 1 >= 1 and (top - 1) not in inside:
            text = lines[top - 2].strip()
            if text and not text.startswith("#"):
                break
            top -= 1
        out.append((top, end))
    out.extend(runs_of_statements(rel))
    return out


def runs_of_statements(rel: str) -> list[tuple[int, int]]:
    """First-to-last line of every consecutive run of top-level statements.

    A citation may name several siblings at once -- a pair of constants, a whole import
    section.  The members have to be *adjacent* (no blank line between them) and the run
    has to start and end on a statement boundary.  Allowing blank lines here would make the
    rule vacuous: in a test file every top-level ``def`` is separated from the next by
    nothing but blanks, so one "run" would span the whole file.
    """
    source = source_of(rel)
    if source is None or not rel.endswith(".py"):
        return []
    statements = sorted((node.lineno, node.end_lineno) for node in _TREE[rel].body)
    out: list[tuple[int, int]] = []
    for i, (first, _) in enumerate(statements):
        last = statements[i][1]
        out.append((first, last))
        for j in range(i + 1, len(statements)):
            if statements[j][0] != statements[j - 1][1] + 1:
                break
            last = statements[j][1]
            out.append((first, last))
    return out


def dotted_span(source: str, name: str) -> tuple[int, int] | None:
    """`Outer.inner` -> the span of `inner` inside `Outer` (field names are not defs)."""
    parts = name.split(".")
    for i in range(1, len(parts)):
        outer = plain_span(source, ".".join(parts[:i]))
        if outer is None:
            continue
        inner = parts[i:][-1]
        found = [
            (a, b)
            for candidate, a, b in nodes_with_spans(source)
            if candidate == inner and a >= outer[0] and b <= outer[1]
        ]
        if found:
            return found[0]
    return None


def plain_span(source: str, name: str) -> tuple[int, int] | None:
    if "." in name:
        return dotted_span(source, name)
    found = [(a, b) for candidate, a, b in nodes_with_spans(source) if candidate == name]
    return found[0] if found else None


def check_entries(section_text: str, failures: list[str]) -> tuple[int, list[tuple[int, int]]]:
    checked = 0
    spans: list[tuple[int, int]] = []

    file_at: dict[int, str] = {}
    current = ""
    offset = 0
    for line in section_text.splitlines(keepends=True):
        header = BULLET.match(line)
        if header:
            current = header.group(1)
        for position in range(offset, offset + len(line)):
            file_at[position] = current
        offset += len(line)

    for match in ENTRY.finditer(section_text):
        spans.append((match.start(), match.end()))
        name, content = match.group(1), match.group(2)
        rel = file_at.get(match.start(), "")
        checked += 1
        label = f"{rel} :: {name} ({content[:56]})"

        source = source_of(rel)
        if source is None:
            failures.append(f"{label}: the file does not exist")
            continue

        old_name = OLD_NAME.search(content)
        for prefix, start, end in REF.findall(content):
            first, last = int(start), int(end or start)
            if last < first:
                failures.append(f"{label}: inverted range {first}-{last}")
                continue
            if name.endswith((".py", ".toml", ".txt", ".md")) or "/" in name:
                lines = source.splitlines()
                if last > len(lines):
                    failures.append(f"{label}: :{first}-{last} past the file's {len(lines)} lines")
                elif first == 1 and name.endswith(".py") and ast.get_docstring(
                    ast.parse(source), clean=False
                ) is None:
                    failures.append(f"{label}: no module docstring to start at line 1")
                continue
            if prefix == "注释 ":
                lines = source.splitlines()
                bad = [
                    n for n in range(first, last + 1) if not lines[n - 1].lstrip().startswith("#")
                ]
                if bad:
                    failures.append(f"{label}: 注释 :{first}-{last} — lines {bad} not comments")
                continue
            wanted = old_name.group(1) if (prefix == "旧 " and old_name) else name
            text = head_source(rel) if prefix == "旧 " else source
            where = f"HEAD" if prefix == "旧 " else "working tree"
            if text is None:
                failures.append(f"{label}: {rel} has no version at {HEAD}")
                continue
            span = plain_span(text, wanted)
            if span is None:
                failures.append(f"{label}: {wanted!r} is not defined in {rel} at {where}")
            elif not (span[0] <= first and last <= span[1]):
                failures.append(
                    f"{label}: {prefix or ''}:{first}-{last} outside {wanted}'s span "
                    f"{span[0]}-{span[1]} at {where}"
                )
    return checked, spans


def check_inline(text: str, failures: list[str]) -> tuple[int, list[tuple[int, int]]]:
    """`path.py:A-B` — the file is named inside the span, so this works doc-wide."""
    checked = 0
    spans: list[tuple[int, int]] = []
    for match in INLINE.finditer(text):
        spans.append((match.start(), match.end()))
        rel, first, last = match.group(1), int(match.group(2)), int(match.group(2))
        if match.group(3):
            last = int(match.group(3))
        checked += 1
        label = f"{rel}:{first}-{last} (line {text.count(chr(10), 0, match.start()) + 1})"
        ranges = extended_spans(rel)
        if ranges is None:
            failures.append(f"{label}: the file does not exist")
            continue
        if last < first:
            failures.append(f"{label}: inverted range")
            continue
        if not any(start <= first and last <= end for start, end in ranges):
            nearest = min(ranges, key=lambda s: abs(s[0] - first))
            failures.append(
                f"{label}: {first}-{last} fits no single node; the nearest span in that file "
                f"is {nearest[0]}-{nearest[1]}"
            )
    return checked, spans


def main() -> int:
    build_index()
    text = DOC.read_text(encoding="utf-8")
    failures: list[str] = []

    regions, origin = region_of(text)
    local_failures: list[str] = []
    entries, local = check_entries(regions, local_failures)
    entry_spans = [(origin[a], origin[b - 1] + 1) for a, b in local]
    inlines, inline_spans = check_inline(text, failures)
    failures.extend(local_failures)
    covered = entry_spans + inline_spans

    # Completeness guard: a reference that neither grammar matched is reported, not ignored.
    unresolved: list[str] = []
    offset = 0
    for line_no, line in enumerate(text.splitlines(keepends=True), 1):
        for match in (*REF.finditer(line), *BARE.finditer(line)):
            absolute = offset + match.start()
            if not any(start <= absolute < end for start, end in covered):
                unresolved.append(
                    f"line {line_no}: {match.group(0)}  |  {line.strip()[:70]}"
                )
        offset += len(line)

    # An 旧 reference must sit inside a matched entry, not float free in prose.
    for match in re.finditer(r"旧 `:\d+", regions):
        if not any(start <= match.start() < end for start, end in local):
            failures.append(f"an 旧 reference is outside any entry, near {match.group(0)!r}")

    for line in failures:
        print(f"FAIL  {line}")
    print(f"\n{entries} entries + {inlines} inline references checked, {len(failures)} failures")
    print(f"{len(unresolved)} reference(s) matched neither grammar (not checked):")
    for line in unresolved:
        print(f"  UNRESOLVED  {line}")
    return 1 if failures else 0


if __name__ == "__main__":
    sys.exit(main())
```
