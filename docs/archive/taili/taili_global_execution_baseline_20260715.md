# Taili 全局执行基线（2026-07-15）

## 不可漂移的目标

- 平地与高难度地形同等重要，不能用一方补偿另一方。
- 平地严格要求核心稳定、速度跟踪、自然步态、轻脚、低滑移、左右与交叉对称。
- 地形允许任务需要的低频倾斜和接触重排，但机身仍要连续、受控，不能随触地摆动或坠落。
- Actor 只使用本体观测和历史。未接触区域、高度扫描和课程标签不得进入 Actor。
- 地形奖励只能依据已经发生的碰撞、接触、承重、关节和机身运动。
- 过渡是次要质量项，不得阻塞或改写原始命令，也不得压过核心、跟踪、步态和地形能力。
- 轻脚只约束摆动与触地过程，不能通过降低支撑力矩获得。

## 已确认的问题

- 旧平地诊断能完成命令，但核心摇晃、前后倾、硬触地和高滑移事件明显。
- 后退低速步幅较小但抬脚偏高，后腿轨迹可被四腿平均误差掩盖。
- 横移旧协调项使用速度绝对值，前后腿反向运动仍可能被误判为一致。
- yaw 跟踪可以提高，但支撑时序、承重对称和动作自然性不足。
- 普通平地错误触地可能触发 terrain response，反而放松平地约束。
- phi2 虽保留 22% 平地，但没有独立平地质量 Gate。
- 楼梯检测已经激活，但前腿放置、承重、机身换层和后腿跟随没有形成。
- 完整换层为零时 terrain_up/down 仍可能为正，失败尝试存在获利漏洞。
- 第一次碰阶是盲态感知证据，却与 stumble 惩罚冲突。
- 下楼主要在脚已经接触下层后触发，缺少“预期触地失败”的被动提前证据。
- 总体 terrain/discrete 指标会掩盖 boxes、上楼梯和下楼梯之间的能力差异。

## 合理动作语义

### 上楼梯

碰阶脚识别 -> 其余腿保持支撑 -> 碰阶脚卸载抬起 -> 上层轻触地 -> 上层承重 ->
机身受控向前向上换层 -> 后腿依次换层 -> 稳定完成一级。

### 下楼梯

预期触地失败或前脚继续探低 -> 后腿保持支撑 -> 前脚受控下探 -> 下层轻触地 ->
下层承重 -> 机身受控下降 -> 后腿依次换层 -> 稳定完成一级。

状态记录只用于训练奖励和课程；不指定关节角，不固定左右先后，不进入 Actor。

## 验收证据

- 平地必须按方向分别报告姿态、角速度/角加速度、机身高度、触地速度、滑移和逐腿轨迹。
- 平地质量不能由地形样本平均值覆盖，也不能被普通 touchdown 激活的 terrain response 放松。
- 上下楼梯分别报告碰撞脚、阶段推进、逐脚承重、完整换层次数、回退和 collapse。
- 第一次碰撞不作为失败；重复踢墙、滑落、自由下落和失去支撑必须明确扣分。
- 课程升级要求分类型真实成功，boxes、stairs、stairs_up 不得互相补偿。
- 诊断使用当前 payload 的当前检查点；旧检查点诊断只能作为历史对照。
- 至少覆盖平地全方向，以及 10/15/18/25/30cm 的上、下楼梯；必要时使用无严格 reset 回放。

## 禁止的局部修补

- 只提高 terrain_up/down 或 tracking 权重。
- 只加强 Gate，却不提供动作结果驱动。
- 用前方扫描提前切换步态。
- 用全局降低刚度、力矩或动作尺度解决脚重。
- 用总体平均值证明最差单腿、最差方向或楼梯能力。
- 未经当前检查点诊断就宣称核心稳定、轻脚或楼梯问题已经解决。

## 楼梯数学合同（2026-07-15 固化）

- 支撑参考只由已经承重的足端拟合；平地保持世界水平，非平地只替换参考面，不降低核心约束总权重。
- 上行由碰阶/水平冲量触发，下行由预期触地失败和受控探低触发；前视扫描和地形标签不进入 Actor。
- 动态碰阶腿、原支撑腿和跟随腿取代固定前腿/后腿顺序。
- 六阶段严格跨帧推进：保持支撑并卸载、抬升/探低、新层轻触地、新层承重、机身换层、其余腿跟随并稳定。
- 阶段记忆在事件内单调增加；势函数只奖励首次阶段增量和首次完整换层，失败由重复碰撞、滑移、冲击、collapse、反向和 timeout 单独表达。
- 首次碰阶豁免 0.27 秒，事件窗口 2.30 秒；持续碰撞不能刷新窗口。
- 新层轻触地前不奖励方向速度；之后只奖励沿命令方向的受控位移，楼梯允许低于平地命令速度。
- Phase 2 同时要求 boxes、上楼和下楼的独立等级、滚动完整成功率与低 collapse 率，任何类型不得被总体平均补偿。
- 当前名义刚度改为 hip/thigh/calf = 110/100/110，阻尼保持 6.2/4.8/4.5；后续 DR 围绕这一真实部署近邻展开。
- 首次 fresh 暴露出核心惩罚量纲失衡：角加速度线性尾部不能直接沿用旧有界尺度。现固定为 free=5、scale=30、weight=0.35；移动高度目标与名义高度统一为 0.52，band=0.04、weight=1.0。核心约束仍保留，但不得压过基础跟踪驱动。
- 第二次早期验证发现原地步态吸引子：方向进展在 0.08m/s 以下被硬清零，而 live imitation 不要求真实推进。现取消进展硬门槛，使用从零开始的连续命令方向比例；imitation 乘现有 progress-style 软门控并保留 floor，步态质量不能替代位移任务。
